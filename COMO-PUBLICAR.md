# Pastinha

Monte dossiês juntando PDFs e fotos: organize arrastando, edite uma página, e baixe como
PDF único, PDF por documento, PDF por página ou imagens JPG/PNG — em 3 qualidades.
Tudo roda no navegador de quem usa: nenhum arquivo é enviado para servidor nenhum.

## Publicar na internet (5 minutos, grátis)

1. Acesse https://app.netlify.com/drop e entre com sua conta Netlify (ou crie uma grátis).
2. Arraste **esta pasta inteira** (`pastinha`) para a página.
3. O Netlify gera um link (ex.: `https://nome-aleatorio.netlify.app`).
4. Em **Site configuration › Change site name**, troque para algo fácil, ex.: `pastinha-dossie` → `https://pastinha-dossie.netlify.app`.
5. Mande o link para o pessoal. Pronto.

Para atualizar depois: no painel do site, aba **Deploys**, arraste a pasta de novo.

## Observações

- O site não aparece no Google (marcado como `noindex`).
- Precisa de internet só para carregar as bibliotecas; os documentos ficam no computador de quem usa.
- Funciona no Chrome, Edge e Firefox, no computador e no celular.
